Lanterna

Show photos, slides, videos and films on your TV with Chromecast.

Choose photos, a video or a film, or drop them on the window, and Lanterna shows them on the TV. One window, no account, nothing leaves your home network.

Download for Windows Install on Linux (Flatpak) Source on GitHub

Windows: the installer needs no administrator rights; a portable zip is there too. Every file of a release is signed with minisign: the public key and how to check a download are in the code signing policy. Linux: from the app's own signed Flatpak repository, updates through GNOME Software; or flatpak install https://daniel-g-carrasco.github.io/lanterna/lanterna.flatpakref.
